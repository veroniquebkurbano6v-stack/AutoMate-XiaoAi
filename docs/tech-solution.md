# AutoMate·小艾 — 你的随身助理

> GOAI 无界应用赛道 · 数字无障碍智能体 · 端侧知识库（检索离线可用）

## 一句话简介

AutoMate·小艾 是一个运行在 Android 上的**数字无障碍智能体应用**：用户只需说一句自然语言（如"帮我在淘宝点杯奶茶"、"用微信给家人发条消息"、"导航去最近的医院"），AI 就自主完成搜索、定位、输入、选择、下单等整个手机操作流程——**无需看清屏幕、无需记住步骤、无需精确点击**。

## 目标用户与痛点

中国有数亿人不方便操作智能手机：视力下降的老年人、低视力/视障者、行动不便者，以及不熟悉数字世界的用户。对他们而言，"点外卖、发消息、查路线"这些日常小事，却是难以跨越的障碍。现有辅助手段（放大镜、读屏）只解决"看"的问题，不解决"做"的问题；本项目让 AI 替他们"看屏幕、点按钮、走流程"。

## 核心闭环（可演示、可验证）

```
用户一句话（语音/文本/悬浮窗/微信远程通道）
  → 决策模型：意图路由 + 工具链（list_apps→kb_read→amap_*→追问）→ 生成分步 Plan
  → 执行模型：多通道感知（无障碍树 / VLM 屏幕描述 / GUI-Plus 坐标直出多通道配合）→ 22 个动作工具逐步执行
  → 端侧知识库：545 条离线 SOP 指引
  → 完成 / 需确认 / 敏感操作拦截后向用户汇报
```

真实任务实录（代表性演示视频，均为真机拍摄、AI 端到端完成）：
1. 用淘宝点奶茶 —— 跨页搜索→选规格→加购
2. 用微信给联系人发消息 —— 一句话 + 自动定位输入/发送
3. 用高德导航到目的地 —— 附近检索→导航
4. 用高德分享位置到微信 —— 跨 App 协作，检索评分最高店铺→分享定位

> 以上为代表性演示；底层是覆盖购物 / 社交 / 导航 / 生活服务的**通用底座**，
> 配合 545 条端侧离线 SOP，可扩展到点外卖、打车、挂号、缴费等更多日常场景。

## 技术架构与亮点

| 能力 | 技术实现 |
|------|---------|
| **完全端侧知识库** | bge-small-zh-v1.5 INT8 ONNX 嵌入 + SQLite 向量 + 关键词融合 + RRF 混合检索，**数据不出手机、检索离线可用**；**识图与操作需联网** |
| **多通道感知** | 无障碍树（文本）→ VLM 屏幕描述（GLM-5.3-Flash）→ GUI-Plus（指令→动作坐标）多通道配合，适配不同障碍人群 |
| **广告弹窗智能拦截** | GLM 屏幕描述携带 `◆广告◆` 标记行 → 解析为广告类型/可否自动跳过/关闭按钮 → 四层兜底关闭（GLM 定位 / 模型坐标 / 无障碍树 / BACK），业务功能弹窗误关防护 |
| **双模型编排** | 决策模型（DeepSeek-V4-Flash）负责任务路由与 Plan 生成；执行模型负责逐步动作决策 |
| **任务工作区上下文控制** | 决策模型把工具关键结果提炼写入工作区、框架自动清理旧工具轮次，防止上下文膨胀 |
| **失败自愈引擎** | FailureCompactor 跨轮记忆失败原因 + 工具熔断，避免同一操作重试风暴烧 token |
| **会话持久化** | Room 2.7.2 + Gson：聊天记录与多会话本地持久化（左侧抽屉切换），退出重进不丢历史、无需重复授权 |
| **无障碍服务自愈** | 开机广播延迟重试 + 周期检查自动恢复无障碍服务，长期运行不掉线 |
| **敏感操作拦截** | 支付/转账等不可逆操作带 `supervised` 标记，先经用户确认再执行 |

## 技术栈与依赖

- **平台**：Android（minSdk 29 / targetSdk 36，Kotlin + Hilt + Coroutines）
- **端侧 AI**：ONNX Runtime（bge-small-zh-v1.5 INT8）、SQLite
- **云端模型（可替换，均有免费额度）**：DeepSeek-V4-Flash（执行/决策）、GLM-5.3-Flash（每轮屏幕视觉描述）、Qwen3-VL-Flash（键盘检测等视觉任务）、GUI-Plus（视觉定位）、高德 MCP（位置/导航）
- **端侧知识库（离线可用仅指检索）**：核心 RAG（知识库检索/SOP 指引）完全离线、数据不出手机；云端用于模型推理（文本决策/屏幕理解/视觉定位，均为国产云端 API）——**识图与操作执行需联网**
