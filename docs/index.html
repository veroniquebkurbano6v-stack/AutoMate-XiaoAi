评委快速上手

APK 不含 API Key · 设置页自填 Key 即可用 · 端侧知识库离线可用

1

安装 APK

安装作品附件中的 AutoMate-XiaoAi-v1.0.apk（Android 10+），在 App「设置」页自行填写模型 Key。

2

开启授权

按引导开启无障碍服务 / 悬浮窗 / 通知 / 电池白名单，约 1 分钟。

3

说出任务

输入“帮我在淘宝点杯奶茶”“用微信给家人发条消息”“导航去最近的医院”，AI 全程代操作。

⬇ 下载安装包（GitHub 镜像 Release） 查看完整文档与技术方案 ↗

APK 不含任何 API Key（避免泄露与合规风险），安装后请进入「设置」页自行填写模型 Key 即可使用（作者为学生个人开发者，暂无力承担大规模 API 消费）。端侧知识库检索离线可用、不依赖任何 Key；屏幕识图与操作决策需联网云端模型。
